# ePhepha Physics Learning App

## Overview
ePhepha is an interactive, gamified educational platform aimed at helping South African learners master NSC Physics concepts. The app focuses on bite-sized lessons, motivational streak systems, and a progress tracking mechanism to keep students engaged and motivated.

## Features
- Endless scrollable lessons based on NSC syllabus
- Interactive questions with immediate feedback
- Streak tracking and motivational messaging system
- Progress bars and unit completion tracking
- National league leaderboard and streak rewards
